# kantei-image スキル

鑑定書の装飾画像を生成する。実行には `codex-image-gen` 系の能力（Codex CLI）が必要。
不在時はスキップしてプレーンテンプレートを使う。

## 入力

- `output/[案件]/subject.json`
- `output/[案件]/modules.json`（命式から守護モチーフを推定）
- 出力先: `output/[案件]/images/`

## 生成する画像

| ファイル | 用途 | プロンプト方向性 |
|---|---|---|
| `cover.png` | PNG鑑定書サムネ＆PDF表紙 | 雲母地・金箔・墨絵の龍鳳・厳粛、和風縦長 |
| `seimei.png` | 姓名判断章扉 | 篆書印・朱印・画数の記号化 |
| `shichu.png` | 四柱推命章扉 | 干支獣・五行カラーの円環 |
| `astrology.png` | 西洋占星術章扉 | ホロスコープ円・星座シンボル |
| `tarot.png` | タロット章扉 | 引かれた3枚のカード絵（実カード意匠） |
| `guardian.png` | 守護モチーフ | 命式から推定した動植物・神獣 |

## 動作

1. 各章のプロンプトを構築（modules.json の値を反映）
2. Codex CLI を並列呼び出し
3. 生成画像を `images/` に保存
4. PDF・HTML・PNGテンプレで `<img>` 参照されるパスに揃える

## プロンプト共通方針

- **テキスト描画は最小限**（gpt-image-2 は日本語OKだが装飾用途では文字を入れない方が安定）
- 縦長は 1024×1536、横長は 1536×1024、章扉は 1024×512
- スタイル: 「和風」「墨絵」「金箔」「雲母地」「鑑定館の正式書簡」

## 失敗時の振る舞い

- Codex CLI 不在 → スキップしてプレーン背景を使う
- 一部画像のみ失敗 → 該当章はプレーン扉に差し替え
- レート制限 → 5秒待機して1回再試行
