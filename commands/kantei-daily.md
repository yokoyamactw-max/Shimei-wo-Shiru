# /kantei-daily

`profile/kantei-profile.md` をもとに、当日のバイオリズム・運勢を短文で生成する。
フル鑑定（`/kantei`）の軽量版。

## 動作

1. `profile/kantei-profile.md` を読む
2. 以下を計算：
   - バイオリズム（身体23/感情28/知性33/直感38）の当日値
   - 九星気学：当日の本命星×日盤
   - 宿曜：当日の宿との関係（本命宿との「命・業・栄・衰・安・危・成・壊」）
   - 西洋占星術：当日のトランジット主要アスペクト（個人天体への触れ）
   - マヤ暦：当日のKINと本命KINの関係
3. `agents/kanteishi` subagent を呼び、200〜400字の短文鑑定を生成
4. チャットに直接出力（ファイル保存はオプション `--save`）

## 出力フォーマット

```
【2026年5月2日 鑑定】

身体30%↗ 感情-80%↘ 知性60%↗ 直感10%→

本日は感情の谷にあり。決断を翌日以降に送るが上策。
言葉により周囲を傷つけるおそれあり、寡黙を旨とせよ。
午後三時以降、知性の頂と直感の交点あり。
重要な思索はその刻に充てよ。
```

## オプション

- `--save`: 結果を `output/daily/YYYY-MM-DD.md` に保存
- `--days N`: 当日から N 日先まで一気に鑑定（旅行や勝負日選定に）
