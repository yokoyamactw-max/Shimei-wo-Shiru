# サンプル鑑定書

本ディレクトリのファイルは Shimei-wo-Shiru プラグインが生成する鑑定書の体裁を示すサンプルです。

| ファイル | 説明 |
|---|---|
| `kantei.png` | 縦長サムネ（SNS共有用、2160×9384px） |
| `kantei.pdf` | A4 詳細鑑定書（5ページ・本文込み） |
| `kantei.html` | ブラウザ表示用 |

## マスク方針

- 被鑑定者名・生年月日・出生地は架空のものに置換 (`鑑定 太郎 / 1985-06-15 10:00 / 東京都(サンプル)`)
- 鑑定文章自体は実データから生成したものを匿名化して流用
- 装飾・章立て・占術所見の構成を見るためのサンプルです

実際の鑑定書は `/kantei` コマンドで `profile/kantei-profile.md` の内容に従って個別に生成されます。
